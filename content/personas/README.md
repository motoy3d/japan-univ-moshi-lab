# 仮想受験者プロファイル

模試の難しさを本番に合わせるための「仮想の受験者」。手順は `docs/authoring/README.md` の「6. 仮想受験者による試し解き」を参照。

| 項目 | 意味 |
|---|---|
| `vocab.zipf50` | この頻度（Zipf 値）の語を知っている確率が 50%。値が小さいほど語彙が多い |
| `vocab.spread` | 知っている確率の曲線のなだらかさ（ロジスティック曲線の幅） |
| `sentenceCollapse` | 1文の中に知らない語がこの数以上あると、その文は「意味が取れなかった文」として丸ごと伏せる |
| `grammarKnown` | 文法問題（IV）の論点を知っている確率。知らない問題には「あやふや」の印を付け、推測で答えさせる |
| `readingWpm` | 入試英文を読む速さ（語/分）。本文と設問・選択肢の語数から必要時間を見積もる |
| `secondsPerMark` / `secondsPerWrite` | 1問あたりの解答時間（秒） |
| `order` | 大問を解く順番 |
| `grammarWeak` | 苦手な（知らない・あやふやな）文法・語法事項。該当する問題は推測で答える |
| `behavior` | 解き方の癖。解答者（AI）への指示として冊子の冒頭に入る |

新しい受験者を増やすときは、このフォルダに JSON を1つ足すだけでよい（例: 偏差値58、英語は得意だが読むのが遅い、など）。

## 較正のしかた

AI の解答者は、伏せた語があっても文脈から推測しきってしまい、そのままでは実際の受験生より高得点になる（第1回の試行では偏差値62の受験者が本番で98%）。そこで `vocab.zipf50`・`sentenceCollapse`・`grammarKnown` は、**本番の過去問での得点率が、その偏差値帯の受験生として妥当な値になるように**調整した値である（実在の生徒の語彙数そのものではない）。新しい受験者を足したら、まず本番の過去問を解かせて得点率を確かめること。
