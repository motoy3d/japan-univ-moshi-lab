# 品質検証レポート：慶應義塾大学 商学部 英語 第1回

確認日: 2026-11-22 ／ 比較対象: 慶應義塾大学が公開している [2026年度 商学部 外国語（英語）](https://www.keio.ac.jp/ja/admissions/faculty/examinations/general-admissions/question-2026/)

## 結論

- **形式**: 大問構成・設問数・書式・解答用紙は本番と一致。
- **正解の一意性**: 全57問を点検し、正解が二つ考えられる設問を4問、不自然な英文を1か所見つけて修正済み。
- **難しさ**: 本番より**やや易しい**。特に長文の語彙・抽象度、文法問題、中文空所の選択肢、設問の文量で差がある（下表）。
- **未実施**: 第三者による90分の通し解き。正解を知らない人（または正解を伏せた別の検証）による確認は、公開前に必要。

## 難しさを本番に寄せるための調整案（次の作業）

1. 長文Iを学術書に近い文体に書き直す（抽象名詞・専門語を増やし、低頻度語の割合を15〜19%に）。
2. 長文の (ii) の選択肢を長く、紛らわしくする（本文の言い換え＋一部だけ誤り、の型を増やす）。
3. IVを本番水準の論点に入れ替える（複合関係詞、準動詞の形、紛らわしい語の区別、慣用的な比較など）。
4. Vの選択肢を低頻度語・比喩の読み取りを含む組み合わせにする。
5. 調整後、正解を伏せた解き直しと、第三者の90分通し解きを行う。
